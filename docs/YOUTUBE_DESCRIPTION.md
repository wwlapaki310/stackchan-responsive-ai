# YouTubeの説明欄（案）

タイトル案: 追従制御・エッジAI（顔）・クラウドLLM（Sarashina/Gemini）を組み合わせた、小型ロボットの環境認識と応答制御

説明欄:

```
M5Stack Stack-chan（K151）に、本体上の顔検出・首の追従制御（エッジAI）と、クラウドのLLM/VLM（Sarashina・Gemini）を役割分担させたデモです。本体で分かることは本体で、分からないことだけクラウドへ聞きます。

・誰もいないとき: 首を左右に大きく振って人を探す（監視モード）
・人を見つけたら: 本体上の顔検出で追従し、挨拶
・自分からクラウドAI（Sarashina）に質問。回答を待つ間も追従・相づちを続ける
・本体で分からないことは、カメラ1枚をクラウドの画像対応AI（Gemini）に見せ、状況の説明文を字幕と声で返す（画像を送るのは「見て」のときだけ・既定オフ）
・本体で分かること（顔の有無・音量）は、本体だけで処理

注意:
・画像の解釈の待ち時間は数秒〜十数秒でばらつきます（動画は一部を編集で短縮）
・追従制御の比較図はシミュレーション（仮定つき）で、実機の性能ではありません
・顔検出の検出率は高くありません。評価実験・ユーザー実験は未実施の作業版です

使用したOSS: pico（MIT）、Open JTalk、HTS Voice "Mei"（CC BY 3.0）、M5Stack BSP ほか
```
